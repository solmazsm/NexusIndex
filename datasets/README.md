<a href="https://components.one/datasets/all-the-news-2-news-articles-dataset">All the News:</a> This dataset contains 2,688,878 news articles and essays from 27 American publications, spanning January 1,2016 to April 2, 2020. It is an expanded edition of the original All the News dataset, which was compiled in early 2017. While the original dataset contains more than 100,000 articles, the new dataset’s greater size and breadth should allow researchers to study a wider selection of media.
To enhance the performance of fake news detection, we propose integrating a threshold-based pseudolabeling strategy within the NexusIndex framework. This approach begins by training the initial model on a labeled dataset, followed by
applying the trained model to predict probabilities on an unlabeled
dataset.


<a href="https://huggingface.co/datasets/davanstrien/WELFake">WELFake:</a> The WELFake dataset consists of 72,134 news articles, with 35,028 classified as real and 37,106 as fake. This dataset was created by merging four well-known news datasets: Kaggle, McIntire, Reuters, and BuzzFeed Political. The goal of this merger was to mitigate the risk of overfitting in machine learning classifiers and to offer a larger corpus of text data to enhance the training process for fake news detection models.

## ABCNews Dataset Labeling

The ABCNews subset used in NexusIndex was constructed from 1,000 randomly sampled headlines from the original ABCNews dataset. Because the original headlines do not include fake/real labels, we used a RoBERTa-based labeling procedure followed by manual verification.

### RoBERTa-Based Initial Labeling

A pretrained RoBERTa model was fine-tuned using the WELFake dataset for binary fake-news classification.

The fine-tuned model was then applied to the 1,000 sampled ABCNews headlines. Each headline was tokenized using the RoBERTa tokenizer and classified as:

- `0` = Fake
- `1` = Real

The RoBERTa model was trained for three epochs using the AdamW optimizer with a learning rate of `2e-5` and a batch size of `16`.

The model-generated classifications were stored as initial pseudo-labels.

### Manual Verification

The RoBERTa predictions were treated as initial pseudo-labels rather than final ground-truth labels. The predicted labels were subsequently manually verified using reliable external information.

The verification process referenced established news and fake-news sources and datasets, including Kaggle, McIntire, Reuters, and BuzzFeed Political.

For each ABCNews headline:

- `predicted_label` represents the initial label generated by the fine-tuned RoBERTa model.
- `label` represents the final label retained after manual verification.

The manually verified `label` was used as the final label in the documented ABCNews subset.

### Final Dataset

After RoBERTa-based initial labeling and subsequent manual verification, the dataset contains:

| Class | Count |
|---|---:|
| Fake | 42 |
| Real | 958 |
| **Total** | **1,000** |

### Dataset Columns

- `headline`: sampled ABCNews headline
- `predicted_label`: initial pseudo-label generated by the fine-tuned RoBERTa model
- `label`: final manually verified label

### Label Encoding

- `0` = Fake
- `1` = Real

The distinction between `predicted_label` and `label` is important. The first records the RoBERTa prediction, while the second records the final label retained after manual verification.
